Layout

  • Custom 36 px title bar (borderless window, egui draws caption buttons; hit-testing via WM_NCHITTEST).
  • Home A: broad list field plus a 420 px duvet detail panel; the seam is the panel edge. Variant B: a near-black stage with one 112 px condensed name, a 6 px apricot seam and a shelf of other PCs.
  • Flow screens: a 300 px near-black step rail and a 640 px max form column, left-aligned (no centred card).
  • Saved PC shows only what the client stores: name, relay address and type, sign-in kept or not, last session time. No online/offline dot, because the client cannot know it without contacting each relay.

Type scale

  • Stage name (B only): Bricolage 112/0.8, wdth 78, wght 710.
  • Detail name: Bricolage 38/0.95, wdth 86. Screen title: Bricolage 28/1.05, -0.025em.
  • Row name 15/720, body 14/450, label 12-13/720, hint 12/450, all Atkinson Hyperlegible Next.
  • Fragment Mono 11-13 only for addresses, codes, timers and transport evidence.

Colour tokens

--void #101214 --field #26282D --surface #2F3138 --surface-raised --ink #F3EFE7 --ink-muted --signal #F0A064 --moss #697A6B --constructive --danger --focus #7AB7FF --paw (recovery)

Apricot appears once per screen: the Connect / Sign in button and the selection marker. Focus stays blue and separate.

Motion and egui cost

  • Hover 120 ms, screen change 180 ms crossfade plus 8 px slide, cubic-bezier(.2,0,0,1). Reduced motion: snap, spinner slows.
  • Approval ring: one expanding stroke, 2.2 s loop. Cheap: a rect stroke with animated alpha.
  • Fitted corners (different radius per corner) are supported by egui CornerRadius per corner. Free.
  • Costly: the 112 px variable-font name needs a pre-rasterised wdth 78 instance (egui has no variable axes); dashed tile border needs a custom painter; the 6-cell code input is a custom widget.
