# Security policy

BubblePlay gives remote control of a Windows desktop, so security reports are welcome and taken seriously.

## Reporting a vulnerability

Please report privately through GitHub: open the repository's **Security** tab and choose **Report a vulnerability**. Do not open a public issue for security problems.

Include what you found, the affected component (Windows host, relay, browser client or Android app), the version or commit, and steps to reproduce. You should get a first reply within a week.

## Supported versions

BubblePlay is in alpha. Only the latest release and the current `master` branch receive security fixes.
