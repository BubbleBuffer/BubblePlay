BubblePlay — Devices

Mockup of the host tray’s native Devices window, 2026-10-27. Static HTML, no Rust. Every state is drawn at real size (560 x 440 px outer: 32 px standard title bar plus 408 px client). Controls are limited to what key_ui.rs already uses: STATIC, BUTTON, EDIT, WM_CTLCOLOR* brushes, system message font, CreateFontW for larger text and one owner-drawn STATIC for the QR. Buttons look like standard Windows buttons on purpose.

Direction: warm milk-cloth window, one duvet header band that marks “this PC” (ownership seam), bright apricot only for the live “online” word. Everything else is ink on milk. Mono (Consolas) only for IDs, the code and the comparison number.

Win32 mapping

Colours are COLORREF values (0x00BBGGRR). Fonts: “system” is NONCLIENTMETRICS.lfMessageFont (Segoe UI 9pt), created once as in message_font(). Larger fonts come from CreateFontW and are deleted with the window. Scale every pixel size by the window’s DPI (GetDpiForWindow / 96).

Notes

  • Colour is never the only signal: error text is also a full sentence, “online/offline” is a printed word, the new row says “New”, the disabled button keeps its label.
  • Contrast: ink on milk 12.6:1, muted-taupe on milk 5.7:1, ERROR_TEXT on milk 4.9:1, cream and apricot on duvet above 6:1.
  • Pages share one window and title, so Back/Cancel never opens a second window. Only the Revoke confirm is a second (modal) window.
